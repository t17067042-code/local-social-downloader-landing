Rights checks, retries, and local folder layout for media pipelines

Online downloader tabs are a bad place to put a repeatable workflow. A local script is only better if it fails clearly, does not overwrite good files, and refuses work you do not have rights to do. This note is the pattern we use around Local Social Media Downloader PRO. It is not a bypass guide and it does not document private platform endpoints.

Use this only for media you created, media the rights holder asked you to process, or other content you already have a legal basis to handle. Platform Terms of Service still apply.

1. Gate the job before any network call

Put the rights decision in your own code, before the tool runs. A small manifest is enough. If the field is missing, the job should exit without fetching anything.

from pathlib import Path
import json, sys

job = json.loads(Path("job.json").read_text())
allowed = {"own_content", "client_authorization", "license_on_file"}
if job.get("rights_basis") not in allowed:
    print("refusing: rights_basis missing or not allowed", file=sys.stderr)
    raise SystemExit(2)
print("ok to process", job["source_url"])

Exit code 2 means “do not retry.” Exit code 1 can mean a transient failure. That split matters more than a clever downloader.

2. Keep filenames stable and idempotent

Hash the source URL and keep the original extension when you know it. Re-running the same job should not create video (1).mp4 copies.

import hashlib
from pathlib import Path

def target_path(url: str, ext: str, out_dir: Path) -> Path:
    digest = hashlib.sha256(url.encode()).hexdigest()[:16]
    return out_dir / f"{digest}{ext}"

# so a killed run does not leave a half file under the final name

3. Retry only the failures that can succeed later

Retry timeouts and HTTP 429/503 with a short backoff. Do not retry a rights refusal, a 401/403, or a URL the tool reports as unsupported. Log the attempt count next to the job id so a later script can skip exhausted jobs.

import time
TRANSIENT = {429, 500, 502, 503, 504}

def should_retry(status: int, attempt: int) -> bool:
    return status in TRANSIENT and attempt < 3

def backoff(attempt: int) -> None:
    time.sleep(2 ** attempt)  # 1s, 2s, 4s

4. Layout that a second script can trust

  • inbox/ — job JSON only, no media
  • work/ — temporary files
  • out/ — finished files named by hash
  • logs/jobs.jsonl — one JSON line per attempt

A later step (resize, caption, archive) should read out/ and the log, not scrape a browser history.
