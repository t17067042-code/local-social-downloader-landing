A job-log contract for local media pipelines

A local downloader is only useful inside a larger script if the next step can tell what happened. Browser tabs do not give you that. A one-line JSON log does. This note is the contract we recommend around Local Social Media Downloader PRO. It does not document private platform endpoints, and it is not a way around Terms of Service.

Process only media you created, media a client authorized you to handle, or other content you already have a legal basis to process. Platform Terms of Service still apply. A missing rights field is a hard stop, not a warning.

1. One JSON object per attempt

Append to logs/jobs.jsonl. Do not rewrite the file. A crashed run should leave earlier lines intact.

{
  "job_id": "2026-10-05-0042",
  "attempt": 1,
  "source_url": "https://example.com/post/you-own",
  "platform": "tiktok",
  "rights_basis": "own_content",
  "started_at": "2026-10-05T08:10:00Z",
  "finished_at": "2026-10-05T08:10:04Z",
  "status": "ok",
  "exit_code": 0,
  "output_path": "out/9f2c1a88b0e4d6c1.mp4",
  "bytes": 1843321,
  "error": null
}

platform is a label your script already knows from the URL host. It is not a claim that every URL on that host is supported. Unsupported URLs should log status: unsupported and stop.

2. Status values a second script can branch on

statusexit_codeNext step
ok0Hand output_path to resize, caption, or archive.
transient1Retry with backoff, up to 3 attempts.
refused2Do not retry. Rights basis missing or not allowed.
unsupported3Do not retry. URL class is outside the tool.
auth_or_forbidden4Do not retry. 401/403 is not a rate-limit.

Keep the set small. Extra statuses become if-branches nobody maintains.

3. Decide from the log, not from the folder

import json
from pathlib import Path

STOP = {"refused", "unsupported", "auth_or_forbidden"}

def latest_by_job(path: Path) -> dict:
    latest = {}
    for line in path.read_text().splitlines():
        if not line.strip():
            continue
        row = json.loads(line)
        latest[row["job_id"]] = row
    return latest

def needs_retry(row: dict) -> bool:
    return row["status"] == "transient" and row["attempt"] < 3

def blocked(row: dict) -> bool:
    return row["status"] in STOP

Reading the newest line per job_id means a later success replaces an earlier timeout without deleting history.

4. What not to log

  • Session cookies, tokens, or private profile URLs.
  • Full response bodies from the platform.
  • A list of accounts you do not have rights to process.

The log is an audit of your own jobs. It should be safe to keep on disk next to the media.
